Privacy Policy

Your privacy matters to us. Here's everything you need to know.

Our Commitment

Escape Button is designed with privacy as the core principle. We access only the minimum browser data needed to function, and everything happens locally on your device. No data is collected, sold, or shared.

What We Access

Escape Button only accesses one type of data:

  • Browsing History – Only accessed to delete non-whitelisted entries when you activate the shortcut

That's it. Nothing else.

What We Do NOT Collect

Escape Button explicitly does NOT collect, store, or transmit:

  • Personal information (name, email, age, location, etc.)
  • Passwords, authentication tokens, or credentials
  • Financial or payment data
  • IP addresses or geolocation data
  • Health or sensitive personal information
  • Website content, messages, or communications
  • User activity (clicks, keystrokes, scrolling, etc.)
  • Browsing patterns or analytics

🔒 Your data never leaves your device. Period.

Data Storage

The extension stores only your Safe Site URL and Whitelist settings locally using Chrome's storage API. This data remains entirely on your device and never leaves it.

No External Communication

  • No data is sent to our servers (we don't have any)
  • No analytics or tracking tools are used
  • No advertisements or third-party services
  • No remote code execution or external scripts
  • All code is self-contained in the extension

Code Transparency

Escape Button is open source. You can inspect every line of code on GitHub to verify exactly what it does and doesn't do.

Updates to This Policy

If we ever make changes to this Privacy Policy, we'll post the update on this page and update the last modified date.

Questions?
